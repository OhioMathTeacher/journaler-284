# Poem texts

One file per poem, named for its `slug` in `poems.js`. `tools/build-poems.py` folds
them in; a poem with no file here shows its byline and a link out instead, which is
what the course pages themselves do.

    # source: <where this text was transcribed from — a URL or a citation>
    # rights: <why it is safe to reproduce here>
    <blank line>
    the poem, line for line, blank line between stanzas

**This repo is public, and GitHub Pages serves it to anyone.** Putting a poem in this
folder republishes it. Only three files are here, all from Project Gutenberg editions
that are unambiguously in the US public domain. Of the other thirteen:

- **Clearly still in copyright** — Plath *Metaphors* (1960), Hayden *Those Winter
  Sundays* (1962), Heaney *Mid-Term Break* (1966), Kinnell *Blackberry Eating* (1980),
  Pastan *Ethics* (1981), Lee *The Gift* (1986), Lyon *Where I'm From* (1993),
  Daniels *Short Order Cook*. These need permission, or they stay as links.
- **Probably free but not verified** — Dunbar *We Wear the Mask* (1896) and Hardy
  *The Voice* (1914) are old enough; I simply could not find a clean transcription to
  copy. Cummings *[since feeling is first]* was published in *is 5* (1926), which is
  US public domain as of 2022, same reasoning.
- **Messier than it looks** — Dickinson. *I dwell in Possibility* was first published
  in 1929 and *Tell all the truth but tell it slant* not until 1945, so the poems are
  not automatically free the way her 1890s ones are. Worth checking before adding.

Nothing here is legal advice. The safe default, and the one the app ships with, is the
link.
